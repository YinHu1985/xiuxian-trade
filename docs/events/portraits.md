# 立绘资源规格

## 总体风格

- **画风**：水墨/工笔风格修仙题材，半身像或七分像
- **色调**：暖色基调，肤色偏暖白，衣袍以国风色系（赭石、藏青、墨绿、月白）为主
- **背景**：透明背景（PNG 或 WebP），方便在深色 UI 上叠加
- **尺寸**：建议 400×600px 以上，保持宽高比 ~2:3
- **格式**：WebP 优先，PNG 备选

## 立绘清单

### 主角方（portrait-left 侧）

---

#### 1. 会长

| 字段 | 内容 |
|------|------|
| **文件名** | `char-player-male.webp` |
| **别名** | 商会会长（主角） |
| **外观** | 中年男子，面容沉稳精明，蓄短须。头戴玉冠或木簪束发，身穿深色锦缎长袍（藏青色/墨绿色），外罩半臂短褂。腰间挂着一枚商会令牌。 |
| **气质** | 沉稳、老练、商人气质中带一丝江湖气 |
| **出现事件** | 几乎所有事件的 portrait-left 侧 |
| **优先级** | ★★★★★（最核心） |
